# PodSherpa prototypes

These sources run independently of the JUCE plugin build.

| Project | Version | Run or install |
| --- | --- | --- |
| [Waypoint](Waypoint/README.md) | v0.1.3 | Standalone Python loudness and delivery app |
| [Switchback](Switchback/README.md) | v0.1.1 | REAPER JSFX stereo utility |
| [Eddy](Eddy/README.md) | v0.1.0 | REAPER JSFX resonance suppressor |

Follow each project’s own launch or installation instructions. Retain the original JSFX filenames and installation locations when replacing an older build so existing REAPER sessions can resolve their effects.
